# S2.8.5a — Ventures: buy + hand panel + the two resource-picker plays

**Epic:** E2.8 · **Tier:** 3 (client) · **Depends on:** S2.8.3a (roll/end-turn — the
main-phase turn loop a human drives) + the DiscardPanel resource-stepper pattern
(S2.8.4b) it reuses · **Status:** DISPATCH-READY.

S2.8.5 (dev cards / «Предприятия») is split a/b along the **board-picking seam**, the
same way S2.8.3/S2.8.4 split:

- **S2.8.5a (this story)** — everything with **NO board picking**: buy a Venture, a
  hand panel listing my held Ventures, and the two plays whose only input is a
  **resource picker** — «Щедрый прилив» (year-of-plenty, take any 2 goods) and «Скупка»
  (monopoly, corner one good). Reuses the DiscardPanel stepper/glyph widget.
- **S2.8.5b (next)** — the two plays that hijack a **board pick**: «Конвой» (knight →
  move-robber tile + victim, reuses the S2.8.4a robber flow) and «Попутный ветер»
  (road-building → up to 2 free road edges). Those need a venture-armed pick source
  injected into `GameScreen`'s phase-driven picker; kept out of 5a to keep it tight.

## Goal

In `main` on my turn a human can **buy** a Venture (drawn card enters my hand) and, from
a **«Предприятие» hand panel**, **play** a held «Щедрый прилив» or «Скупка» via a resource
picker. Today the «Предприятие» button (`BottomDeck.tsx:160`, `hud.actionVenture`) is
permanently `disabled` — no Venture UI exists at all. This story lights it up for buy +
the two resource-picker plays.

## Core contract (verified — client never calls `validate`; advisory hints only)

All intents flow through the generic `store.dispatchIntent` (proven live for every other
S2.8.x story); the server re-validates. **No protocol/net/server work** (the protocol
already round-trips all dev-card intents — `packages/protocol/src/messages.test.ts:37-57`).

- **Buy:** `{ type: 'intent.buyDevCard', playerId }` (`core/types.ts:961`). Cost =
  `{ fleece:1, barley:1, iron:1 }` (`ruleProfile.ts:395`, `CLASSIC_PROFILE.devCards.buyCost`).
  Main-phase only; rejects `CANNOT_AFFORD` (`validate.ts:1458`) or `DECK_EMPTY` when
  `state.devDeckRemaining <= 0` (`validate.ts:1464`). The drawn card lands in my
  `state.devCards[myPlayerId]` as **both** `held[kind]++` and `boughtThisTurn[kind]++`
  (so it's un-playable until next turn — see below). A drawn `victoryPoint` silently adds
  VP. The buyer's own client sees the real drawn kind (own holdings are unredacted).
- **Play (year-of-plenty):** `{ type:'intent.playDevCard', card:'yearOfPlenty',
  resources:[ResourceType, ResourceType] }` (`core/types.ts:991`) — a 2-tuple (repeats
  allowed: `['timber','timber']` or `['timber','clay']`). Main-phase only. Rejects
  `BANK_EXHAUSTED` if the bank lacks a requested good (`validate.ts:1599`).
- **Play (monopoly):** `{ type:'intent.playDevCard', card:'monopoly', resource:ResourceType }`
  (`core/types.ts:997`) — collects ALL of that good from every other player. Main-phase only.
- **Play gating (every `playDevCard`)** — `validate.ts:1486-1503`:
  - `state.devCardPlayedThisTurn === true` → `DEV_CARD_ALREADY_PLAYED` (**one Venture per
    turn**).
  - `held[card] <= 0` → `CARD_NOT_HELD`.
  - `held[card] - boughtThisTurn[card] <= 0` → `BOUGHT_THIS_TURN` (a card bought THIS turn
    can't be played until next turn).
- **State shapes** (`core/types.ts`): `state.devCards?: Record<PlayerId, DevCardHoldings>`
  where `DevCardHoldings = { held: Partial<Record<DevCardKind,number>>; boughtThisTurn:
  Partial<Record<DevCardKind,number>> }` (`:138`). `DevCardKind = 'knight' | 'roadBuilding'
  | 'yearOfPlenty' | 'monopoly' | 'victoryPoint'` (`:64`). `state.devDeckRemaining?: number`
  (`:255`, absent ⇒ full deck of 25 — but for a display just show it when present).
  `state.devCardPlayedThisTurn?: boolean` (`:289`).

## Requirements

### 1. `hud/devCardActions.ts` (new, pure — mirror `hud/discardActions.ts` discipline)
- `DEV_CARD_BUY_COST` — the `{ fleece:1, barley:1, iron:1 }` cost. Prefer importing the
  cost from core if it's exported (grep `packages/core/src/index.ts` for
  `CLASSIC_DEV_CARD_PROFILE` / a dev-card profile export and use `.buyCost`); else mirror
  the literal with a `// mirrors ruleProfile.ts:395` comment (same pattern as
  `board/buildLegality.ts`'s `buildCost`).
- `myHoldings(state, myPlayerId): DevCardHoldings` — `state.devCards?.[myPlayerId] ?? { held:{},
  boughtThisTurn:{} }`.
- `playableCount(state, myPlayerId, kind): number` — `held[kind] - boughtThisTurn[kind]`
  (clamped ≥ 0). The count of that kind playable THIS turn.
- `canBuyDevCard(state, resources, myPlayerId): boolean` — advisory mirror: `phase==='main'`
  AND `selectIsMyTurn` AND affords `DEV_CARD_BUY_COST` (each `resources[r] >= cost[r]`) AND
  `(state.devDeckRemaining ?? deckSize) > 0`. (Deck size default: if you can cheaply read the
  full deck length from core use it; else treat `undefined` remaining as ">0", since a fresh
  match has a full deck — the server is authoritative on `DECK_EMPTY` regardless.)
- `canPlayVenture(state, myPlayerId, kind): boolean` — advisory: `phase==='main'` AND
  `selectIsMyTurn` AND `!state.devCardPlayedThisTurn` AND `playableCount(kind) > 0`. **Scope
  note:** 5a only wires `yearOfPlenty` and `monopoly` to a real play; `knight`/`roadBuilding`
  are board-pick plays deferred to 5b, and `victoryPoint` is never playable. Keep
  `canPlayVenture` general (it's correct for any kind), but the PANEL only renders a play
  action for yearOfPlenty/monopoly this story.
- Unit-test: playableCount (held 2 / bought 1 → 1; held 1 / bought 1 → 0; missing kind → 0);
  canBuyDevCard true only in main+my-turn+affordable+deck-remaining; canPlayVenture false when
  `devCardPlayedThisTurn`, false off-turn, false for a bought-this-turn-only card, true for a
  held-since-last-turn yearOfPlenty in main on my turn.

### 2. `hud/VenturePanel.tsx` (+ `.css`) — the hand panel + pickers
A **docked panel over the Chart** (DESIGN.md §6/§7, like `DiscardPanel`, NOT a hard modal —
the board stays visible). Rendered by `GameScreen` when the venture panel is open (see §4).
Three internal views (component-local `useState` for which is showing — transient, self-
contained, same rationale as DiscardPanel's local selection):

**(a) List view (default):**
- A **«Купить предприятие»** button showing the cost (glyph + count per resource, reuse the
  `BottomDeck` build-cost row style) and the deck-remaining count when `state.devDeckRemaining`
  is present. Disabled unless `canBuyDevCard`. On click → `dispatchIntent({ type:'intent.buyDevCard',
  playerId: myPlayerId })`. (Same 400ms double-dispatch guard as DiscardPanel is a nice-to-have;
  a stale double-buy just costs a second card — but the guard is cleaner.)
- **My held Ventures**, one row per kind I hold (`held[kind] >= 1`), in a fixed kind order
  (`knight, roadBuilding, yearOfPlenty, monopoly, victoryPoint`) so rows don't reflow. Each row:
  the lore card name (see i18n), the count `held[kind]`, and — for `yearOfPlenty`/`monopoly`
  ONLY — a **«Разыграть»** button enabled per `canPlayVenture`. `knight`/`roadBuilding` rows
  render their count with **no** «Разыграть» this story (disabled, `aria`/title "доступно в
  следующем обновлении" is acceptable, OR simply omit the button — state your choice; do NOT
  wire a play). `victoryPoint` (Передовица) shows its count with no action (passive VP).
  - When a play is blocked because a card was **bought this turn** (`playableCount 0` but
    `held ≥ 1` because all copies are `boughtThisTurn`), the «Разыграть» is disabled — a small
    hint line "куплено в этот ход" is welcome (localized) so the human isn't confused. When
    blocked because a Venture was already played this turn, the disabled state is enough.
- Empty state: if I hold no Ventures, show a localized "Нет предприятий на руках" and just the
  buy button.
- A **«Закрыть»** (`common.cancel` or a close key) to dismiss the panel.

**(b) Year-of-plenty picker** (entered from the yearOfPlenty «Разыграть»):
- Prompt "Щедрый прилив: выберите 2 товара". A −/+ stepper per resource (ALL 5, since you take
  from the bank not your hand) bounded `0..2`, reusing the DiscardPanel/`trade.ts` widget
  (`emptyBundle`/`clampStep`/`TRADE_RESOURCE_ORDER`, `ResourceGlyph` + `RESOURCE_KEY`). A
  "выбрано {n} / 2" counter. Confirm **«Разыграть»** enabled only when the selection sums to
  EXACTLY 2. On confirm → expand the bundle to a 2-tuple (e.g. `{timber:2}`→`['timber','timber']`,
  `{timber:1,clay:1}`→`['timber','clay']`) and `dispatchIntent({ type:'intent.playDevCard',
  card:'yearOfPlenty', resources: tuple })`. «Отмена» → back to list.

**(c) Monopoly picker** (entered from the monopoly «Разыграть»):
- Prompt "Скупка: выберите товар". A single-select of the 5 resources (radio-style buttons with
  `ResourceGlyph` + name + `aria-pressed`; buttons disable/highlight, never disappear — §6). A
  **«Разыграть»** confirm enabled only when one resource is chosen. On confirm →
  `dispatchIntent({ type:'intent.playDevCard', card:'monopoly', resource })`. «Отмена» → back.

**Post-dispatch:** do NOT optimistically mutate — the server fold updates `state.devCards` /
resources / `devCardPlayedThisTurn`; the panel reflects the new state on the next render (a
played card's count drops, «Разыграть» disables via `devCardPlayedThisTurn`). It's fine to
close the panel (or return to the list) after a successful-looking dispatch; a rejected play
raises the existing `NoticeBar`, and the panel/pickers must remain usable (don't lock the UI —
mirror DiscardPanel's `justDispatched` self-heal if you add a guard).

### 3. `hud/store.ts` — UI-only panel-open flag
- Add `ventureOpen: boolean` (UI-only, never part of `gameState`, never sent) + `setVentureOpen(open)`
  — the same "two sibling HUD pieces share it" rationale as `buildMode`: `BottomDeck` (the
  «Предприятие» button) SETS it, `GameScreen` READS it to render `<VenturePanel/>`. Initial `false`.
- Reset `ventureOpen: false` in `applySnapshot` (a fresh match join — never leak an open panel
  across matches; same discipline as `robberPendingTile`). Do NOT reset it on every `applyEventBatch`
  fold (that would slam the panel shut on any broadcast mid-interaction). Off-turn auto-hide is
  handled by the render gate in §4, not by clearing the flag on folds.

### 4. Placement (`hud/BottomDeck.tsx` + `hud/GameScreen.tsx`)
- `BottomDeck.tsx`: replace the permanently-`disabled` «Предприятие» button (`:160-162`) with a
  toggle — `disabled` unless `main phase && my turn` (the phases where buy AND
  yearOfPlenty/monopoly are legal); `aria-expanded={ventureOpen}`; onClick toggles `ventureOpen`.
  On «Завершить ход» (and on `closeBuild`) also `setVentureOpen(false)` so it doesn't linger.
  Do not otherwise touch the build selector.
- `GameScreen.tsx`: render `<VenturePanel/>` in the chart area (next to `DiscardPanel`) when
  `ventureOpen && gameState.phase === 'main' && selectIsMyTurn(...)` — so it auto-hides if the
  turn/phase moves on while open. It coexists with the (main-phase) trade dock and build prompt;
  make sure it doesn't overlap the trade dock footprint (position like DiscardPanel; if they'd
  collide, dock it on the opposite side — state your choice; the board must stay visible).

## Constraints
- Server authoritative; every gate here is an advisory client mirror (button-enable only) — never
  block the dispatch pipeline beyond enabling the button. A slipped-through illegal intent →
  server reject → existing `NoticeBar`.
- Client never has the seed / never calls `validate` (the drawn card is server-revealed via the
  folded `devCard.bought` event into `state.devCards`; the client just renders it).
- **NO board picking in this story.** Do not arm any `pickMode`, do not touch `BoardScene.ts`,
  `useRobberPlacement`/`useBuildPlacement`/`useSetupPlacement`, or `GameScreen`'s phase-driven
  `placement` selection. Knight & road-building plays are S2.8.5b.
- Do NOT touch `packages/core`, `packages/protocol`, `packages/server`, or `memory/`. Do NOT
  touch S2.8.4's discard/robber code beyond IMPORTING the shared stepper helpers
  (`trade.ts`, `resourceGlyphs`, `resourceLabels`, `components/Button`).
- Touch ONLY: new `hud/devCardActions.ts` (+ test), new `hud/VenturePanel.tsx` (+ `.css`),
  `hud/store.ts`, `hud/BottomDeck.tsx`, `hud/GameScreen.tsx`, `i18n/keys.ts` +
  `locales/{en,ru,uk}.ts`.
