# S1.1.2 — Fair board generation from seed (constraint-aware, deterministic)

## Goal

Generate the Classic board layout **deterministically from the match seed**:
tile types, number tokens (no adjacent red 6/8), port assignment, robber start.
Same seed → identical board, forever. This is the first real consumer of
`rng.ts` beyond dice.

## Files

- `packages/core/src/boardgen.ts` (NEW)
- `packages/core/src/boardgen.test.ts` (NEW)
- `packages/core/src/types.ts` — additive: board-layout fields on `GameState`
  (tile types/tokens by tileId, port contents by slot, robber tileId) and a
  `board.generated`-style `GameEvent` if the design lands on event-sourced
  setup (preferred: setup emits events like everything else).
- `packages/core/src/reduce.ts` / `validate.ts` — only what's needed to apply
  the setup event(s); no gameplay rules here.
- `packages/core/src/index.ts` (re-export).
- Golden fixtures may need re-goldening if GameState shape grows — document it.

## Map slice

- `rng.ts`: `deriveValue(seed, streamIndex)`, `shuffle(items, seed, streamIndex)`
  (Fisher-Yates consuming indices `streamIndex..streamIndex+n-2`), golden seed
  `'skervik-golden-seed-1'` used in existing tests.
- S1.1.1 `board.ts` topology (tile/vertex/edge ids, port slots).
- Plan §3 "RNG stream discipline": board generation consumes a **reserved
  documented stream range**; write the chosen map into
  `docs/wiki/rng-stream-map.md` (NEW, this story creates it).

## Spec

- **Inputs:** `seed` (string), topology. **Outputs:** deterministic layout.
- Tile mix: 4 forest, 3 hills(clay), 4 pasture, 4 fields, 3 mountains, 1 desert
  — use the repo's mechanical resource ids (`timber/clay/fleece/barley/iron`,
  desert produces nothing). Shuffle onto the 19 tiles from the seed.
- Tokens `2,3,3,4,4,5,5,6,6,8,8,9,9,10,10,11,11,12` onto non-desert tiles.
  **Constraint: no two red tokens (6/8) on adjacent tiles.** Strategy:
  deterministic bounded retry — attempt k uses shuffle at
  `streamIndex = BASE + k * STRIDE`; first constraint-satisfying attempt wins.
  Bound attempts (e.g. 64) and prove in tests that the golden seed satisfies
  within bounds; on exhaustion return the last attempt with a documented flag
  (never throw nondeterministically).
- Ports: shuffle the 9 classic contents (4× generic 3:1, 5× resource 2:1 — one
  per resource) onto the fixed port slots from S1.1.1.
- Robber starts on the desert tile.
- Setup is **event-sourced**: generation produces event(s) carrying the full
  layout (so replay needs no generator re-run), applied via `reduce`.

## Acceptance criteria

- [ ] Same seed → byte-identical layout (test runs generator twice + through
      event replay).
- [ ] Red-token constraint holds for the golden seed AND a property test over
      ≥50 derived seeds (`seed-0`…`seed-49`).
- [ ] Every consumed stream index is documented in `docs/wiki/rng-stream-map.md`
      and stable (golden assertion on at least one full layout for the golden seed).
- [ ] Replay/golden determinism tests green (re-goldened consciously if state
      shape changed — noted in Implementation notes).
- [ ] `pnpm -r typecheck && lint && test && build` green; zero runtime deps.
