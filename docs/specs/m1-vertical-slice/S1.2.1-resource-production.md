# S1.2.1 — Resource production on roll (+ the gameplay RNG stream scheme)

## Goal

Rolling the dice on a player's turn produces resources: for the rolled total,
every tile carrying that number token pays its adjacent settlements (1) and
cities (2), unless the robber sits on the tile. This story also **fixes the
gameplay RNG stream scheme** (`streamIndex = eventIndex * K + slot`) that every
future random draw (dev-deck shuffle, robber steal) will obey — the counterpart
to the reserved board-gen band from S1.1.2.

  event (carries both die faces + the total), a `resources.produced` event

## Spec — gameplay RNG scheme (decide here, NEVER change)

- Gameplay draws live in the low band `[0, 1_000_000)`; board-gen owns
  `[1_000_000, …)` (S1.1.2). Scheme: **`streamIndex = state.eventIndex * K + slot`**
  with a fixed small `K` (pick `K = 8`) and a documented slot map per event type
  (slot 0 = die A, slot 1 = die B; slots 2–7 reserved for later same-event draws
  like the robber steal-pick in S1.3.1). Write the slot map into
  `docs/wiki/rng-stream-map.md`.
- **Headroom guard (deferred nit from S1.1.2 review):** with `K = 8` the
  gameplay band reaches `1_000_000` only at `eventIndex = 125_000` — far beyond
  any real match. Encode this as an explicit invariant: assert (or document with
  a cheap runtime check + comment) that `eventIndex * K + K <= 1_000_000`, so a
  gameplay draw can never collide with the board-gen band. Note it in the wiki.
- Each die is a `1..6` draw from `deriveValue(seed, streamIndex)`; record both
  faces in `dice.rolled` so replay recomputes nothing from the seed.

## Spec — production

- On roll total `T` (≠7; the 7 branch is S1.3.1 — for now reject or no-op 7 with
  a documented `TODO(S1.3.1)` reason, do NOT implement robber here):
  for every non-desert tile whose token == `T` and which the robber is NOT on,
  each adjacent settlement's owner gains 1 of that tile's resource, each adjacent
  city's owner gains 2.
- **Bank exhaustion (Classic):** if the bank cannot pay the full amount owed of
  a given resource to ALL entitled players, NOBODY receives that resource this
  roll (all-or-nothing per resource type). Compute against the finite bank pool.
- Payout amounts are **explicit** in `resources.produced` (replay must not
  recompute). Robber-on-tile tiles pay nothing.
- Phase: `roll` → after producing, advance to the `main` phase (build/trade land
  in S1.2.2+/E1.3); S1.2.4 formalizes the full FSM — keep the transition minimal
  but correct here.

- [ ] Production correctness: fixtures cover settlement=1, city=2, robber blocks

      rule (negative case where nobody is paid).
- [ ] RNG scheme documented in `rng-stream-map.md` (K, slot map, headroom guard)

- [ ] Out-of-turn / wrong-phase rolls rejected with the right `RejectReason`.
- [ ] Golden replay re-goldened consciously if state shape changed (documented);
      reducer stays pure (no-mutation test passes).
