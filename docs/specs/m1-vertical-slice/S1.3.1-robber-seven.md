# S1.3.1 — The 7 / robber: discard, relocate, steal (+ knight play)

## Goal

Resolve rolling a 7 and playing a knight — the two ways the robber moves.
On a 7: every player holding >7 cards discards floor(half) (own choice via
intent); then the mover relocates the robber and steals 1 random card from an
adjacent victim. The **knight** dev card (deferred from S1.2.3) shares the exact
relocate+steal path and increments the player's played-knight count for largest
army (S1.3.4). The random steal-pick is the first user of the reserved
same-event RNG slots from S1.2.1.

## Spec

- **Discard on 7:** every player with >7 resource cards must discard
  `floor(handSize / 2)`. The specific cards are the player's OWN choice (via a
  `discard` intent) — the FSM waits in the discard sub-phase until all owing
  players have discarded (order-independent). Amounts/cards explicit in events.
- **Relocate:** the roller (or knight-player) moves the robber to a DIFFERENT
  tile (not its current tile). Reject same-tile / off-board.
- **Steal:** from the settlements/cities adjacent to the new robber tile, the
  mover picks ONE victim who has ≥1 card; steal 1 card chosen by the PRNG
  (`deriveValue(seed, eventIndex*K + <steal slot>)` → index into the victim's
  sorted hand). Record the stolen resource explicitly in the steal event. If no
  adjacent victim has cards, no steal (documented no-op).
- **Knight:** `playDevCard('knight')` enters the SAME relocate+steal path
  (no discard step), respects one-dev-card-per-turn and not-bought-this-turn,
  and increments the played-knight counter (largest army, S1.3.4). May be played
  before the roll (Classic) — decide + document the phase guard.
- Reject reasons (extend): must-discard-first, wrong-discard-count,
  robber-same-tile, no-such-victim, victim-has-no-cards, not-in-robber-phase.

## Acceptance criteria

- [ ] Seeded steal is deterministic + replayable (same seed+state → same stolen
      card); the steal event records the concrete resource (no re-draw on replay).
- [ ] Discard flow: >7 triggers discard for exactly the owing players, correct
      floor(half) counts, FSM resumes only after all discards; negative tests for
      wrong count / discarding when not owing.
- [ ] Robber relocation legality (different tile, on-board) + victim selection
      (adjacent, has cards) each have happy + negative tests.
- [ ] Knight play routes through the same steal logic and bumps the knight
      counter; one-per-turn + not-bought-this-turn guards tested.
- [ ] Determinism: replay deep-equal; reducer pure; goldens conscious.
- [ ] `pnpm -r typecheck && lint && test && build` green; zero runtime deps.
