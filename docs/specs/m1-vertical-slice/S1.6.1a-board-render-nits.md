# S1.6.1a — Board render: two owner-approved follow-up nits (mist layering + desert token)

## Goal

Two small, owner-approved fixes to the S1.6.1 board render (both from the
`lead-review` MERGE-WITH-NITS pass). Client-only, no behavior change beyond these two.

1. **Nit-1 (contrast, DESIGN.md §10 / §9):** the ambient board-wide mist currently
   sits ON TOP of the number-token discs, ink digits, and the `--hot-number` red 6/8,
   washing the most information-dense elements with a ~8–22% white haze. Re-layer so
   the mist hazes the *tile field* (atmosphere kept) but the **number tokens + robber
   render ABOVE the mist and stay crisp.**
2. **Nit-2 (desert color):** desert tiles reuse `--chart-paper` as a placeholder.
   DESIGN.md §2.3 now defines a dedicated **`--res-desert` = `oklch(0.66 0.03 70)` /
   `#9e8f7f`** (a barren grey-dun, ~0.20 darker than fleece/chart-paper). Use it for
   the desert tile fill.

## Spec

### Nit-1 — mist below tokens
- Current (S1.6.1): render order draws the ambient mist overlay on `world` AFTER the
  tiles layer, over a radius covering the whole 19-tile field, so it overlays the
  chart-paper token discs + digits + pips + robber (`BoardScene.ts` around the mist /
  `onTick` region the reviewer cited).
- Fix: split the render so the **number-token discs (fill + `--chart-paper-ink` /
  `--hot-number` digits + probability pips) and the robber marker are in a layer drawn
  ABOVE the mist overlay.** Recommended order: `sea → tiles (fills + patterns +
  extrusion) → mist overlay → tokens + robber`. The tile field keeps its atmospheric
  haze; the info-dense elements stay crisp. Keep the mist's slow ambient pulse and its
  `prefers-reduced-motion` static-frame pause (do NOT regress the §9 gate) and the
  ≥4s period.
- Optional, at worker discretion: also cap the mist peak alpha slightly lower if,
  after re-layering, the tile-field haze still reads too strong — but re-layering is
  the primary fix; do not over-tune.
- The "built once, only mist alpha animates per tick" property must hold (no per-frame
  full re-render introduced by the re-layering).

### Nit-2 — desert token
- Add `desert: 0x9e8f7f` to `theme/canvasColors.ts` (the frozen sRGB hex for the new
  `--res-desert`), and add `--res-desert: oklch(0.66 0.03 70);` to `theme/tokens.css`
  §2.3 group — verbatim from DESIGN.md §2.3.
- In `board/boardModel.ts`, map `TileKind === 'desert'` fill to the new desert color
  (was `chartPaper`). If the `?? chartPaper` fallback for an absent/unknown kind exists,
  leave its robustness behavior for nit-3 (deferred) — but the *desert* case itself must
  now resolve to the desert color, not chart-paper.
- Update any test that asserted desert fill == chart-paper to assert == the new desert
  color (`boardModel.test.ts`).
