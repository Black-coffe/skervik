# S1.2.3 — Development cards: deck, buy, play

## Goal

A seed-shuffled development-card deck, buying a card (Classic cost), and playing
the non-robber card types. The **knight** card's effect (move robber + steal)
is a robber action — it is DEFERRED to S1.3.1, which owns robber relocation for
both the 7-roll and the knight; this story defines the knight in the deck and
makes it buyable, but wires its *play* in S1.3.1 (documented dependency).

## Files

- `packages/core/src/types.ts` — additive: `buyDevCard` + `playDevCard(kind, …)`
  intents; deck state (counts, not identities exposed to other players); events
  for buy/play; per-player dev-card holdings + "bought this turn" marker +
  "dev card played this turn" marker + knight-count (for largest army in S1.3.4).
- `packages/core/src/validate.ts` — buy (affordability, deck non-empty, one draw)
  and play branches (one dev-card play per turn; a card bought this turn is
  unplayable this turn except VP counting toward win).
- `packages/core/src/reduce.ts` — apply buy (draw top, debit) and play effects.
- `packages/core/src/devcards.test.ts` (NEW) + fixtures.
- `packages/core/src/index.ts` (re-export).
- `docs/wiki/rng-stream-map.md` — record the deck-shuffle draw range.

## Spec

- **Deck (Classic, 25 cards):** 14 knight, 2 road-building, 2 year-of-plenty,
  2 monopoly, 5 victory-point. Shuffled from the seed **at game start** — decide
  and DOCUMENT its stream range in `rng-stream-map.md` (either the reserved
  board-gen-style band alongside layout, or an `eventIndex*K` slot at the setup
  event; be explicit and disjoint from dice draws).
- **Buy:** cost = 1 fleece + 1 barley + 1 iron; deck must be non-empty; draw the
  top card; it is private to the buyer; marked "bought this turn" (unplayable
  same turn, except VP cards silently count toward victory).
- **Play (one per turn):**
  - road-building: place 2 roads free (reuse S1.2.2 road legality; may place
    fewer if no legal edge / supply exhausted).
  - year-of-plenty: take any 2 resources from the bank (respect bank supply).
  - monopoly: name a resource; all other players hand you their entire holding
    of it (explicit transfer amounts in the event).
  - victory-point: not "played" — hidden, counts toward the win threshold
    (surfaced only at victory per E1.3 S1.3.4).
  - **knight: DEFERRED to S1.3.1** — reject `playDevCard('knight')` here with a
    documented `TODO(S1.3.1)` reject reason, but DO count bought knights so
    S1.3.4 largest-army has the data. (Alternatively coordinate with S1.3.1;
    default is defer.)
- Reject reasons (extend): can't-afford, deck-empty, card-not-held,
  bought-this-turn, already-played-dev-card, wrong-phase, out-of-turn,
  knight-deferred.

## Acceptance criteria

- [ ] Deck shuffle deterministic from seed (same seed → same order), draw order
      is top-of-deck, composition totals 25 with the exact Classic multiset;
      shuffle range documented + golden-asserted.
- [ ] Buy: correct debit, deck decrement, privacy (other players' view carries
      only a count), bought-this-turn unplayable (negative test).
- [ ] Each playable card has a happy-path + relevant negative test; one-dev-card-
      per-turn enforced; monopoly/year-of-plenty amounts explicit in events.
- [ ] Knight play rejected with the documented deferral reason; knight-count
      still increments on... (buy only — knights aren't counted until played per
      Classic largest-army; keep the counter but increment where S1.3.1 plays it).
- [ ] Determinism: replay deep-equal; reducer pure; goldens conscious.
- [ ] `pnpm -r typecheck && lint && test && build` green; zero runtime deps.
